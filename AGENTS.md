# MeshRMM agent instructions

## Project status

MeshRMM is not production ready; it is still in heavy development. There are no
customers or production deployments to protect. Do not preserve backwards
compatibility for its own sake: change or remove APIs, wire protocols, database
schemas, configuration formats, and on-disk data freely when that yields a cleaner
design. Do not add migrations, compatibility shims, deprecation paths, or fallbacks
for old versions unless explicitly asked.
